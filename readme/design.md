## 로고 : Tdl

**T**o-**d**o **l**ist의 모노그램입니다. T의 세로획이 d의 기둥이 되고, 그 끝에서 필기체 l이 이어집니다.
직접 그린 스케치를 바탕으로 같은 팔레트를 적용해 SVG로 만들었습니다(SVG 변환은 Claude Code 활용). 파비콘은 SVG를 기본으로 쓰고, SVG를 지원하지 않는 브라우저를 위해 PNG(32px, 180px)를 함께 넣었습니다.

## 팔레트

| 이름 | 색 | 쓰임 |
|---|---|---|
| Tomato Red | `#C9483C` | 주요 버튼, 강조 글자, 취소선, 카드 |
| Pool Blue | `#76AFC0` | 카드 |
| Lemon Cream | `#F0D98C` | 카드, 핀 상자 항목 |
| Paper | `#FBF6EC` | 배경 |
| Ink | `#1E3A6E` | 본문 글자, 선 |

할 일 카드는 토마토 → 풀블루 → 레몬 순서로 색이 돌아가고, 완료한 카드는 종이색으로 바래면서 빨간 굵은 취소선만 선명하게 남습니다.

## 타이포그래피

- **Pretendard** : 본문과 큰 제목. 굵고 자간을 좁힌 그로테스크 느낌으로 "Things to do"를 크게
- **Instrument Serif (이탤릭)** : *today*, *my list*, *pinned* 같은 포인트 단어
- **IBM Plex Mono** : `date`, `title` 같은 라벨과 날짜

## 무드보드

Pinterest에서 컬러 팔레트, 습관 체크표(Daily Rituals), 플래너 제품 사진을 모아 무드보드를 구성하고, 이를 기준으로 색 · 글꼴 · 카드 모양을 정했습니다.

- 컬러 팔레트 이미지 → 토마토 · 풀블루 · 레몬 3색 조합
- 습관 체크표 → 크림색 종이 배경, 남색 잉크, 네모 체크칸, 모노 라벨, 이탤릭 포인트 문구
- 플래너 제품 사진 → 큰 그로테스크 제목, 색면 카드

레퍼런스 이미지의 저작권은 각 제작자에게 있어 저장소에는 포함하지 않았습니다.
